# P00 font notice evidence

The four `*-OFL.json` files contain exact publisher license text fetched from the public Google Fonts repository on 2026-10-22. Their URLs, SHA-256 hashes and retrieval scope are recorded in [font-license-evidence.json](../font-license-evidence.json). Each JSON `text` field preserves the original UTF-8 text, including trailing whitespace and line endings. Hashes apply to that decoded text. This avoids changing the publisher's bytes or applying whitespace-check exceptions. These are evidence containers, not new project-authored licenses or a decision to bundle fonts; future distribution needs the actual license text exported with its assets.

The evidence manifest also records every archived WOFF2 file's hash and embedded name-table entries, extracted with fontTools 4.62.1 from the pinned Feishin archive. Name IDs are 0 copyright, 1 family, 5 version, 13 license description and 14 license URL. These font hashes cross-reference the immutable source [asset ledger](../assets.csv). The optional archive checker validates those source hashes; default tests validate the decoded license text hashes and cross-reference font records without requiring fontTools or the ignored archive.

Current publisher license snapshots are not exact-version provenance for each binary. In particular, Inter's publisher copyright says 2020 versus embedded 2016, and Hebrew's says 2022 versus embedded 2024. Preserve both records and resolve the actual distribution package before copying those fonts into a release. Poppins and Japanese copyright indications agree in this inspection. Symbola has only its archived embedded free-use statement and historical author URL; no authoritative complete redistribution text was obtained, so it remains unselected. Future replacement must preserve required character coverage and workflows.

No font binaries were added. No dependency versions or application runtime changed. See [third-party notices](../../../../THIRD_PARTY_NOTICES.md) for the release obligations and remaining gaps.
