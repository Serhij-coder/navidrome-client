No now-playing/scrobble response was captured in this short run; reporting semantics remain covered only by the separately bounded headless/adapter evidence.

## Optional reproduction

Use a controlled external reference environment, never a user's live profile/server. Prerequisites: the hash-verified original source, frozen dependencies, explicit original web/remote/desktop builds, Playwright 1.56.1 Chromium, matching Electron 43.7.0 and a virtual display. Desktop build command from the reference root: `node node_modules/electron-vite/bin/electron-vite.js build` (159 main, 15 preload and 3,369 renderer modules; observed renderer build 45.70 s). Mixed import, empty chunk, TagLib browser externalization and large-chunk warnings did not fail bundling. These are build observations, not startup/performance measurements.

Serve a temporary copy of original web output at loopback port 18180. Set its `settings.js` to `window.ANALYTICS_DISABLED = true;` before serving. Provision the six fixed loopback fixture ports in the [server runbook](live-servers.md). The credential JSON must have `admin`, `password` and `reader_password`; protect it with mode 0600. The desktop runtime directory must contain original `package.json`, `out/main`, `out/preload`, `out/renderer`, `out/remote`, required assets and frozen node_modules. Keep private profile/download roots separate from a fresh public output directory. Both harnesses reject equal/nested roots (including symlinked existing ancestors) and credential files inside public output before creating directories or loading a browser. Do not reuse a profile or output directory from a previous attempt.

```sh
node tests/reference/p00-browser-capture.cjs PLAYWRIGHT_PACKAGE SOURCE_ROOT docs/app/baseline/source-audit.json CREDENTIALS_JSON PRIVATE_WEB_ROOT PUBLIC_WEB_ROOT
```

Paths are positional external inputs, not package installs or application dependencies. The desktop harness reserves loopback port 18433, creates only an external launcher/guard, generates separate remote credentials and closes its processes. Web capture returns nonzero if any operation fails; failed runs are diagnostic evidence, never accepted workflow results. Native failure diagnostics remain private.

Publish only reviewed public outputs. JSON/string/authenticated-URL redaction removes known passwords/tokens and credential fields; request records omit headers, bodies and auth query values. Verify output against all private passwords/tokens, inspect screenshots at readable resolution, and confirm masks actually match inputs. Default integrity tests verify source-audit/screenshot/DOM hashes, PNG dimensions/CRCs and saved behavior. Symlink-specific guard coverage skips explicitly when the host cannot create directory symlinks; ordinary path guards remain tested. They do not rerun UI automation or prove absence of arbitrary unknown secrets in images.
