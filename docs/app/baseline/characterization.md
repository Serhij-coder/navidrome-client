C01-C09 are inputs to [ADR-009](../adr/009-source-differences.md). No Rust behavior has been changed. Raw original source is preserved in the local immutable baseline; the tracked results contain synthetic values only.

Listen accumulation at `use-scrobble.ts:286-312` uses positive media-position deltas <=5 seconds, not wall time. Consequently 2x speed can accumulate media time twice as fast per wall second; this is source inference pending a clocked runtime trace. Rebaseline jumps and reset when returning below five seconds; the restart boundary also uses ten seconds. Keep the OR threshold and upstream media-time rule unless later evidence warrants an explicit superseding decision. Required runs include 0.5x/1x/2x, pause, forward seek, backward seek, repeat, same-song new occurrence, private mode and failed submission.

Remaining queue traces: every Play enum variant, empty/single/duplicate/mixed-server queue, shuffled moves and Up Next boundary drops, current removal, repeat stop/pause, previous at 10/11 seconds, next/previous album, hydration and mixed-server save rejection. Fixtures and journeys specify these cases; there is no claim they passed in the original or the rewrite.
