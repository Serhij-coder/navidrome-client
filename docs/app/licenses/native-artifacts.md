# P01 native AppImage provenance

P01.06/P01.07 development packaging uses [package-appimage.py](../../../tools/app/package-appimage.py) and [native_notices.py](../../../tools/app/native_notices.py). This bounded collector supports Ubuntu 24.04 x86_64/aarch64 builds with dpkg-query, ldconfig and readelf. The deployment tool remains architecture-specific and SHA256 pinned. These records improve provenance; they do not certify distribution licensing or close P01/P13 release gates.

The packager first asks linuxdeploy to populate the AppDir without producing an artifact. It then records every staged ELF file, including in-tree symlink aliases, under `usr/share/doc/feishin-p01/native/inventory.json`. Each distribution ELF is matched to a library explicitly registered by ldconfig using basename, ELF machine and GNU build ID. Matching rejects missing or ambiguous candidates. It records both source and bundled SHA256 because linuxdeploy patches ELF runtime search paths. It queries the installed binary package, binary version, source package, source version and architecture through dpkg-query, then copies that package's installed copyright file byte-for-byte with its SHA256 and source path. It does not synthesize a license statement from package names.

The project's executable is bound separately to the supplied source executable's machine, build ID and SHA256, with the project's bundled GPL notice. It is not attributed to a distribution package. An AppRun symlink to that executable is recorded as another path. Symlinks escaping the staging directory and unrecognized native ELF files fail packaging. No tool-owned ELF is silently attributed to Ubuntu; a future tool-owned executable needs independently verified source/tool identity support before it can be accepted.

After adding the inventory and notices, a second linuxdeploy invocation produces the AppImage. The packager rechecks the staged ELF set, symlink targets and bundled hashes before accepting the result. It retains checksum verification, runtime dlopen library selection and refusal to overwrite an existing output. Tests use patched synthetic ELF identities and mocked package metadata; they do not substitute for actual artifact extraction, clean-environment startup, resource loading or playback evidence.

The embedded AppImage runtime lies outside the AppDir inventory. The pinned outer linuxdeploy digest identifies the packaging input, not the generated runtime's version or source revision. Its exact licensing/source obligations remain open, as do native copyleft corresponding-source obligations, system driver exclusions, distribution compatibility and actual evidence for each architecture. Existing historical artifacts remain unchanged. The collector is not a complete legal audit, general SBOM or promise that installed copyright files satisfy every redistribution obligation.
