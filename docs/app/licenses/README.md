# P01 dependency notice provenance

P01 adds Rust dependencies pinned in [Cargo.lock](../../../Cargo.lock). The [collector](../../../tools/app/notices.py) copies exact license/notice files from downloaded registry packages, preserves their manifests/readmes for attribution and includes nested egui font texts. It inventories all target dependencies conservatively, even when a particular artifact does not link them. Rust 1.92.0 [license and copyright texts](toolchain/COPYRIGHT) were retrieved from the `rust-lang/rust` `1.92.0` tag; [MIT](toolchain/LICENSE-MIT) and [Apache-2.0](toolchain/LICENSE-APACHE) are included with generated bundles, together with the standard-library COPYRIGHT-library.html shipped by that exact rustup toolchain.

Several published crates omit their repository-level license files. [Overrides](registry-overrides.json) identify package versions, exact `.cargo_vcs_info.json` upstream Git revisions, and retrieved texts under `upstream/`. Two verbatim source notices with upstream trailing whitespace are stored as deterministic gzip files and expanded byte-for-byte by the collector; the original texts are not normalized. The evidence includes egui/eframe and AccessKit licenses, not copied application implementation. Do not replace exact-revision evidence with current-branch text silently.

Four package/version entries (`dispatch` 0.2.0, `hexf-parse` 0.2.1, `r-efi` 5.3.0 and 6.0.0) have no standalone license file in the inspected package/revision. They carry explicitly labeled standard SPDX license texts from `spdx/license-list-data` tag `v3.27.0`, plus their published Cargo author/license metadata. These templates are not newly discovered copyright statements or a completed notice review. Exact attribution/notice requirements remain a release gate. `r-efi` is inventoried under its declared MIT alternative; this does not choose LGPL for this artifact.

The chosen egui default-font dependency contains Hack/DejaVu/Bitstream, Ubuntu, Noto Emoji and the egui emoji icon font. The collector includes all four font text files (Hack-Regular, OFL, UFL and emoji icon MIT, as provided by the crate). These replace neither the unresolved upstream Feishin font provenance nor the required multilingual/RTL coverage audit. No upstream Feishin font binary is reused.

The development SVG icon and deterministic 32x32 PNG thumbnail are original GPL-3.0-only artwork under `tools/app/assets/`. Project LICENSE and THIRD_PARTY_NOTICES accompany both web roots and the development AppImage. mpv/FFmpeg are external tools, not bundled here. Their build/license obligations must be examined if distributed later.

AppImage tooling is digest-checked linuxdeploy build `07333c6` (2026-10-01); it includes an AppImage runtime and automatically bundles linked system libraries. This initial notice inventory is not a complete runtime/native-library/SBOM audit. Required dlopen libraries, exact runtime source/licensing, bundled-library copyright/source obligations and distribution floors remain open before release. P01 smoke artifacts are local development results; neither publishing nor release certification occurred. The CI builds and exercises artifacts locally without an upload step.

The Windows IPC candidate adds target-only Tokio 1.48.0 and interprocess 2.4.6, with their transitive versions pinned in Cargo.lock. The collector successfully retrieved all 371 registry notice sets after this change, including these packages and their exact registry license files. Native Unix and WASM roots do not link this Windows transport; the conservative generated inventory still lists every lockfile target. This does not close the native AppImage/runtime release audit.

[Native AppDir provenance](native-artifacts.md) now links staged ELF identities and original/bundled hashes to exact Ubuntu binary/source package versions and copied copyright bytes. It verifies the ELF set after the output pass. The embedded AppImage runtime is outside that inventory; its source/licensing and native corresponding-source obligations remain open. The optional Linux MPRIS probe uses zbus 5.19.0 and async-io 2.6.0 already present in the lockfile; no package versions were upgraded.

The optional Linux [GStreamer candidate](../p01/gstreamer-candidate.md) adds 24 registry packages without upgrading existing versions. `notices.py --features feishin-native-spike/gst-probe OUTPUT` successfully collects 395 selected-graph registry notice sets, compared with 371 for the default graph. Optional features are not automatically included by default Cargo metadata. An exploratory all-features collection failed closed on the pre-existing block 0.1.6 package's missing standalone license evidence; broader optional-feature licensing remains open. The [native candidate record](gstreamer-candidate.json) separates inspected Ubuntu core/plugin package notices from complete codec/runtime source obligations. GStreamer and its helper are not included in the default AppImage or selected for distribution.
